## The line

> I'm on holiday. My inbox is being looked after by the same person who waters my plants: nobody, and the plants are dead.

## How it works

`main.py` (Python 3, standard library only) writes that single line to
`/output/entry.txt` — 120 characters, one line, no trailing newline.
It validates the gate itself before writing: 1–160 characters, single line,
not only whitespace.
